## Main Navigation Structure

### Top-Level Navigation Bar
The platform has five main sections accessible from the top navigation:

1. **Home** - Dashboard and overview
2. **Inventory** - Vehicle inventory management
3. **My Sites** - Website configuration and content management
4. **Media** - Media asset management
5. **Contacts** - Contact and lead management
